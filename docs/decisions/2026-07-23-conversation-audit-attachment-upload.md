# 对话控制评估核实附件上传

日期：2026-07-23

## 决策

允许 Codex 通过已绑定的天源浏览器 session，调用固定白名单浏览器脚本，将一个本地附件上传到资产基础法底稿“评估核实”的“查证资料索引”字段。

不开放任意 JavaScript、任意页面点击或任意接口调用。

## 动作协议

- `tianyuan.preview_audit_attachment_upload`
  - 定位指定科目、行号和“查证资料索引”。
  - 检查 `operation-upload-cell`、编辑锁和上传分类。
  - 不注入文件、不上传、不保存。
- `tianyuan.upload_audit_attachment`
  - 必须复用连接状态返回的 `sessionId`、`bindingId`、Codex `projectId` 和 `threadId`。
  - 必须传入确认文本 `确认上传并保存`。
  - 读取用户明确指定的一个绝对文件路径。
  - 浏览器脚本注入文件、点击上传弹窗保存、点击底稿保存并回读目标单元格。

## 安全边界

- 只接受 `查证资料索引`，不允许调用方指定其他字段。
- 行号必须为用户视角的第 2 行或以后。
- 科目代码必须符合 `C3-1-2` 一类标准格式。
- 文件必须是普通文件，最大 20MB。
- 只允许常见文档、表格、图片和压缩包扩展名。
- 文件内容只在任务执行期间以内存 Base64 传递，不持久化、不返回本机完整路径。
- 编辑锁、权限提示、保存按钮禁用或上传单元格只读时停止。
- `/attach/upload`、`/cell_file/classify_upload`、`/assignment_draft/save` 必须分别核验。
- 只有底稿保存业务成功且目标单元格回读非空，才报告正式成功。

## 运行要求

- Chrome 天源浏览器工作台侧栏必须保持打开。
- 当前天源页面必须绑定到调用方 Codex 项目和对话。
- Connector Bridge 必须在线。
- 扩展版本不低于 `0.5.0`。
- Codex 插件版本不低于 `0.2.0`。
