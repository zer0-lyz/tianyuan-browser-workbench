# 天源浏览器工作台

## 支持环境

- macOS 10.15 或以上；
- Apple Silicon 芯片：M1、M2、M3、M4 等；
- Google Chrome；
- 可以访问天源评估系统和 MCP 服务。

本发行包不支持 Intel Mac，也不支持 Windows。

## 安装

1. 解压整个压缩包，不要只单独复制其中某个文件。
2. 双击 `安装.command`。
3. 如果 macOS 阻止运行，请右键 `安装.command`，选择“打开”。
4. 根据提示输入 Mac 管理员密码，安装天源 CLI 和必要环境。
5. 安装完成后会自动打开 Chrome 扩展管理页和扩展文件夹。
6. 在 Chrome 中打开“开发者模式”。
7. 点击“加载未打包的扩展程序”。
8. 选择 Finder 中已经打开的 `extension` 文件夹。

扩展固定 ID：

`lkflndcnklpeaejohaacoaolnmhgigoc`

## 首次配置

1. 打开天源系统页面。
2. 点击 Chrome 工具栏中的“天源浏览器工作台”。
3. 进入“连接配置”。
4. 点击“配置 MCP”，输入使用者自己的 MCP token。
5. 点击“授权 CLI”，在打开的页面完成授权。
6. 点击“启动/检查”，确认 Helper、MCP、CLI 均已连接。

安装包和扩展中不包含任何人的 MCP token、Cookie、Authorization、密码或验证码。

## 当前功能

1. 批量保存底稿；
2. 批量退出编辑；
3. 导出资产基础法明细表；
4. 导出资产基础法申报表；
5. 批量调整明细表打印格式；
6. 批量调整申报表打印格式；
7. 批量上传文件；
8. 批量清理附件；
9. 通过 GitHub Releases 检查和下载更新。

## 文件位置

- 扩展：`~/Applications/天源浏览器工作台/extension`
- Helper：`~/.tianyuan-workbench/native-helper`
- Python 环境：`~/.tianyuan-workbench/python`
- 打印格式脚本：`~/.tianyuan-workbench/dependencies/天源评估系统/print-format-skills`
- Helper 日志：`~/.tianyuan-workbench/native-helper/native_host.log`

## 卸载

1. 双击 `卸载.command`；
2. 在 Chrome 扩展管理页移除“天源浏览器工作台”。

卸载脚本不会删除导出的 Excel 文件，也不会卸载系统 Python 或天源 CLI。

## 使用提醒

- 正式执行批量保存前，先使用预演模式。
- 编辑锁是硬门禁，插件不会绕过编辑锁。
- 打印格式首次处理正式文件时，建议选择“在源文件夹创建打印版副本”。
- 如果 WPS 正在打开目标工作簿，建议关闭工作簿后再处理。
