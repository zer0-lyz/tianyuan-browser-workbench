# 其他应付款科目层级过滤静态验证

验证时间：2026-07-23 09:07 CST

## 问题

用户截图显示天源左侧科目树存在：

```text
流动负债
  应付职工薪酬
  其他应付款
    其他应付款
```

但插件科目清单只显示：

- `C3-1-2 银行存款`
- `C4-4 长期股权投资`
- `C5-8 应付职工薪酬`

未显示 `其他应付款`。

## 原因

页面显示树里的 `其他应付款` 比普通科目多一层父子结构。原过滤逻辑先做精确层级匹配，只要已经匹配到其他科目，就提前返回结果，导致 `其他应付款` 没有进入后续宽松匹配流程。

## 修复

修改 `extension/src/sidepanel/sidepanel.js` 中的 `filterSubjectsByVisibleContext`：

- 先保留页面显示树与 MCP 科目的精确匹配；
- 再补充同名科目的宽松层级匹配；
- 合并结果并按 `科目代码 + 科目名称` 去重；
- 避免同名深层显示科目被提前过滤掉。

追加增强：

- 统计 MCP 科目中的同名重复节点。
- 只要页面可见名称中出现该名字，且 MCP 里同名节点超过一个，就保留整组同名科目。
- 用于兜住 `其他应付款 -> 其他应付款` 这类页面同名父子结构。

## 静态验证

```bash
node --check extension/src/sidepanel/sidepanel.js
```

结论：通过。
