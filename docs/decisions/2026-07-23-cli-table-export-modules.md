# CLI 表格导出模块决策

日期：2026-07-23

## 功能范围

首页新增两个独立功能：

- 资产基础法明细表导出；
- 资产基础法申报表导出。

两个功能都只选择公司，不选择科目。流程统一为：

1. 自动加载当前项目公司清单；
2. 用户多选公司并确认；
3. 用户通过 macOS 文件夹选择器选择存放目录；
4. 点击导出；
5. 显示阶段进度、CLI 日志和最终文件清单。

## CLI 映射

- 明细表：`tycpv export-asset-detail-table`
- 申报表：`tycpv export-asset-declare-table`

共同参数：

- `--project-id`
- `--company-ids`
- `--out-dir`

## 安全边界

- 插件不能自行读取任意本机路径，目录必须由用户通过系统文件夹选择器授权。
- Native Host 只允许两个导出子命令，不接受任意命令文本。
- 项目 ID 和公司 ID 只允许数字。
- 输出目录必须是已存在的绝对目录，并在执行前解析真实路径。
- CLI 使用参数数组启动，不通过 shell 拼接。
- 导出结果和日志不得包含 Cookie、Authorization、密码、验证码或 token。

## 进度口径

CLI 未提供结构化百分比，因此进度条根据稳定日志阶段估算：

- 启动和 MCP 连接；
- 读取项目；
- 读取公司树；
- 逐公司导出和写入文件；
- 导出完成。

最终只有 CLI 退出码为 0 时显示 100% 和成功状态。
