# 侧栏多页面工作台决策

日期：2026-07-23

## 决策

天源浏览器工作台侧栏采用单 HTML 内部路由，不为每个功能创建独立扩展窗口。

路由包括：

- `#home`：功能首页；
- `#connections`：连接配置；
- `#batch-save`：批量保存底稿；
- `#batch-exit`：批量退出编辑。

## 状态边界

- Helper、MCP、CLI 连接状态为全局状态，始终显示在顶部。
- 公司和科目范围属于功能模块状态。
- 批量保存与批量退出编辑分别保存自己的清单、勾选、确认、日志和证据。
- 页面切换只移动共享范围组件，不重新创建科目树或公司树。
- 批量任务运行期间锁定路由按钮。

## 扩展规则

后续新增功能时，在首页增加入口和独立路由页面，并复用工作范围组件和日志证据组件。不得修改已固定的页面科目树镜像和显示状态判断逻辑，除非有单独回归任务和真实页面证据。
