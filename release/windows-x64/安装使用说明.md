# 天源浏览器工作台 Windows x64 测试版

## 支持环境

- 64 位 Windows 10 或 Windows 11；
- Google Chrome 或 Microsoft Edge；
- 可以访问天源评估系统和 MCP 服务；
- 当前包不支持 Windows ARM，也不支持 32 位 Windows。

## 安装

1. 将整个 ZIP 解压到本机磁盘，不要在压缩包预览窗口内运行。
2. 双击 `安装.cmd`。
3. 如果 Windows Defender SmartScreen 提示未知发布者，核对文件来源后选择“更多信息”与“仍要运行”。
4. 安装程序会自动检测已有 CLI、Python 和打印格式依赖，并选择快速安装或完整安装。
5. 安装完成后，完全退出所有 Chrome 或 Edge 窗口，再重新打开浏览器。
6. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，开启“开发者模式”。
7. 点击“加载已解压的扩展程序”或“加载未打包的扩展程序”。
8. 选择安装程序打开的扩展目录：

   `%LOCALAPPDATA%\TianyuanWorkbench\projects\天源评估系统\extension`

扩展固定 ID：

`lkflndcnklpeaejohaacoaolnmhgigoc`

## 自动安装模式

安装程序不再默认重复安装全部依赖。

### 快速安装

满足以下条件时直接复用已有环境：

- `tycpv --version` 可以正常运行；
- 已安装 Python 3.9 或以上版本；
- Python 中已有 `openpyxl 3.1.5` 或以上版本和 `et_xmlfile`。

快速安装会同步扩展、Native Helper、Bridge、Connector、Agent 插件缓存、打印脚本及 Native Messaging 注册，不复制包内 CLI 和便携 Python。

如果已有 Python 但缺少打印格式依赖，安装程序会先从包内两个离线 wheel 快速补齐，不联网下载。

### 完整安装

只有出现以下情况时才使用包内备用依赖：

- 找不到可运行的 `tycpv.exe`：运行包内 Windows CLI 安装程序；
- 找不到 Python 3.9+；
- 已有 Python 无法安装或加载打印格式依赖：复制包内便携 Python。

安装结束后，窗口和检查报告都会显示实际采用的安装模式与耗时。

升级安装通过统一本机安装脚本同步全部运行目录；各目录先复制到暂存位置并校验后切换。已有的 Agent 来源、绑定和本机凭据引用会被保留。

## 首次配置

1. 打开天源系统底稿页面。
2. 点击 Chrome 工具栏中的“天源浏览器工作台”。
3. 进入“连接配置”。
4. 点击“配置 MCP”，由使用者本人输入 MCP token；token 只用于当前侧边栏会话。
5. 点击“授权 CLI”，在打开的页面完成天源账号授权。
6. 点击“启动/检查”，确认 Helper、MCP、CLI 均显示已连接。

安装包和扩展不包含任何人的 MCP token、Cookie、Authorization、密码或验证码。

## 业务功能

1. 批量保存底稿；
2. 批量退出编辑；
3. 导出资产基础法明细表；
4. 导出资产基础法申报表；
5. 批量调整明细表打印格式；
6. 批量调整申报表打印格式；
7. 批量上传文件，支持目标列、目标位置、行号映射、顺序上传、统一保存和断点继续。
8. 批量清理附件，清空所选行的“查证类核实程序”和“查证资料索引”，保留“查证核对情况”。

顶部工具区另提供：

- 通过 GitHub Releases 检查并一键更新全部组件；
- 填写功能建议、配置问题或故障反馈，并在本机保存草稿或复制反馈内容。

## 本机安装位置

- 扩展：`%LOCALAPPDATA%\TianyuanWorkbench\projects\天源评估系统\extension`
- Native Host：`%LOCALAPPDATA%\TianyuanWorkbench\native-helper`
- Connector：`%USERPROFILE%\plugins\tianyuan-browser-connector`
- Codex 缓存：`%USERPROFILE%\.codex\plugins\cache\personal\tianyuan-browser-connector\0.4.2`
- 便携 Python：`%LOCALAPPDATA%\TianyuanWorkbench\python`，仅在需要回退时创建
- 打印格式脚本：`%LOCALAPPDATA%\TianyuanWorkbench\print-format-skills`
- 检查结果：`%LOCALAPPDATA%\TianyuanWorkbench\安装检查结果.txt`

## 测试顺序

1. 先检查顶部 Helper、MCP、CLI 三项状态。
2. 先用一个公司、一个科目和“预演模式”测试批量保存。
3. 再用一个公司、一个科目测试批量退出编辑。
4. 导出功能先选择一个公司和临时空文件夹。
5. 打印格式功能首次请选择工作副本，并使用“在源文件夹创建副本”。
6. 不要用正式文件直接测试覆盖模式。
7. 批量上传和批量清理首次只检查识别、选择与确认页面，不要在正式底稿执行写入测试。
8. 版本更新页面先执行“检查更新”；发现新版本时点击“更新全部组件”，确认下载、校验、安装和扩展重新加载进度正常。

## 卸载

1. 双击 `卸载.cmd`；
2. 在 Chrome 扩展管理页移除“天源浏览器工作台”。

卸载脚本不会删除用户导出的 Excel 文件，也不会卸载天源 CLI 或用户原有的 Python。如果快速安装曾向已有 Python 补充 `openpyxl`，该 Python 用户库也不会被卸载脚本删除。

## 已知验证边界

本测试包在 macOS 上完成了源码、安装包结构、Windows PE、Native Messaging 协议和离线依赖校验，但仍需在真实 Windows x64 + Chrome 或 Edge 环境完成首次安装验证。测试结果请连同 `%LOCALAPPDATA%\TianyuanWorkbench\安装检查结果.txt` 一并反馈。

扩展与 Native Host 使用同一个 SHA-256 `runtimeBuildId`，用于阻止旧扩展与新 Connector 混用。安装或更新后必须完全退出浏览器，再重新打开并重新加载本机扩展目录。

安装器会在启动 Connector 前同时核对扩展版本、Native Helper 版本和 `runtimeBuildId`。若仍出现 `CONNECTOR_VERSION_MISMATCH` 或 `CONNECTOR_START_TIMEOUT`，请直接提供 `%LOCALAPPDATA%\TianyuanWorkbench\安装检查结果.txt`，不要手工复制单个运行文件或修改注册表来拼接版本。

反馈时重点提供：

- `安装模式`；
- `安装耗时`；
- CLI、Python 和 openpyxl 的实际路径及版本；
- Helper、MCP、CLI 三项连接状态。
