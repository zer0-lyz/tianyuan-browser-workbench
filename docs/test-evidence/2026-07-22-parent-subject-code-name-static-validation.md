# 父级科目代码名称显示静态验证

时间：2026-07-22 23:23:24 CST

## 问题现象

用户截图显示隐藏科目过滤已生效，但父级节点仍显示为 `C3`、`C3-1`、`C4`、`C5`，未显示科目名称。

## 原因

隐藏科目过滤后，父级节点通常不作为保存项进入最终清单；树形结构由叶子科目代码前缀补出来，因此父级标题只剩代码。

## 修正内容

- 在过滤显示科目前，先用 MCP 全量科目建立 `科目代码 -> 科目名称` 映射。
- 对保留的显示科目补齐父级 `parentCode/parentName/path`。
- 父级节点显示为 `科目代码 科目名称`。
- 对常见顶层科目提供窄兜底：
  - `C3 流动资产`
  - `C3-1 货币资金`
  - `C4 非流动资产`
  - `C5 流动负债`
  - `C6 非流动负债`
  - `C7 所有者权益`

## 验证结果

- `extension/src/sidepanel/sidepanel.js` 语法检查通过。
- `native-helper/native_host.js` 语法检查通过。
- `native-helper/server.js` 语法检查通过。
- `extension/manifest.json` JSON 解析通过。
- 本地样本验证：`C3-1-2 银行存款` 可生成路径 `流动资产/货币资金/银行存款`，根节点标题为 `C3 流动资产`。

## 后续验证

重新加载 Chrome 扩展后，点击“加载科目”。预期父级显示为 `C3 流动资产`、`C3-1 货币资金` 等。
