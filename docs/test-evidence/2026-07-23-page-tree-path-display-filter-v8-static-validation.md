# 2026-07-23 页面科目路径与显示状态过滤 v8 静态验证

## 目标

修复两个问题：

1. 父级科目没有名称或名称错位；
2. 全量模式会把隐藏科目带入批量处理范围。

## 修复内容

- 页面适配器为每个科目树节点记录真实父级路径。
- MCP 科目匹配到页面节点后，使用页面路径参与父级名称重建。
- 父级名称从路径末端按科目代码层级对齐。
- 面板恢复为只展示显示状态科目：
  - 页面树完整时，以页面实际显示树为准；
  - 页面树不可用或不完整时，以 MCP 显示字段为兜底；
  - 隐藏科目不进入可选清单，不会参与批量执行。
- 页面适配器版本更新为 `2026-07-23-page-tree-path-v7`。

## 验证结果

- `extension/src/sidepanel/sidepanel.js` 语法检查通过。
- `extension/src/injected/page_adapter.js` 语法检查通过。
- `extension/src/content/content.js` 语法检查通过。
- `extension/manifest.json` JSON 解析通过。

## 验证边界

需重新加载未打包扩展后点击“加载科目”，确认父级名称恢复，并确认隐藏科目不再显示在可选清单中。
