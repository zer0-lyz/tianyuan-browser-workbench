# 天源 Connector 连接优先方案

## 决策

先实现连接面板、当前天源标签页绑定和能力探测，暂不实现浏览器内 Agent 对话、指令队列和任意浏览器自动化。

## 链路

`Chrome Side Panel -> Native Messaging -> 127.0.0.1:40415 Connector Bridge`

侧栏读取当前天源页面的轻量上下文后，向本地 Bridge 注册 session。Bridge 只保存项目、公司、科目、页面类型、标签页编号和能力摘要，并通过 heartbeat 维持在线状态。

## 能力边界

- 可读取：当前页面上下文、项目/公司/科目、页面显示科目树和门禁摘要。
- 可预演：批量保存、批量退出编辑。
- 需确认执行：正式保存、正式退出编辑；必须保留编辑锁、登录状态和回读门禁。
- 本机执行：CLI 表格导出、Excel 打印格式处理。
- 暂不支持：任意浏览器自动化、任意 JavaScript 执行、浏览器内 Agent 对话。

## 安全规则

- Bridge 只监听 `127.0.0.1:40415`。
- 跨域请求仅允许固定工作台扩展 ID和本机客户端来源。
- 不保存 Cookie、Authorization、密码、验证码、MCP token 或完整页面对象。
- session 上下文只保留轻量摘要；正式写入仍由现有功能页执行，不由 Bridge 直接执行。

## 后续

连接稳定后，再用真实天源页面逐项验证“读取、定位、预演、确认执行、回读”能力，再决定是否接入 Agent 对话层。
