# 天源浏览器工作台反馈库

此仓库仅用于接收天源浏览器工作台的用户反馈，不存放产品源码、客户资料、项目文件或账号凭据。

## 分类

- `feature`：功能建议
- `configuration`：安装或配置问题
- `bug`：程序故障
- `experience`：使用体验
- `needs-triage`：等待维护人员分流

## 处理规则

1. 每条反馈必须有匿名反馈编号。
2. 反馈正文只保留用户主动填写的内容和固定白名单环境信息。
3. 发现客户名称、项目编号、文件路径、Cookie、Authorization、token、密码或验证码时立即删除敏感内容。
4. 修复完成后在源码仓库建立对应任务或版本记录，不在本仓库存放源代码。
5. 此仓库保持私有，不向普通插件用户直接开放。
