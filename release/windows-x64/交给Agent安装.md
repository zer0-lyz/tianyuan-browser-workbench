# 交给 Agent 安装

请将以下任务连同本文件所在的完整解压目录交给能够操作 Windows 桌面、PowerShell 和 Chrome 的 Agent。

## 可直接使用的提示词

你现在需要在这台 Windows 电脑上安装并验证“天源浏览器工作台”。

要求：

1. 先确认系统为 64 位 Windows 10 或 Windows 11，并确认 Google Chrome 或 Microsoft Edge 已安装。
2. 不要把程序直接安装在 OneDrive、企业微信缓存或 ZIP 压缩包内。
3. 先检查 `tycpv --version`、Python 版本以及 `python -c "import openpyxl, et_xmlfile"`，只记录是否可用和版本，不读取任何账号凭据。
4. 运行当前目录中的 `安装.cmd`，等待全部 7 个步骤完成。安装器会自动选择快速安装或完整安装，不要手工重复安装已有依赖。
5. 安装失败时，保留完整错误信息，不要绕过 SHA-256 校验，不要自行关闭安全软件。
6. 安装成功后读取：
   `%LOCALAPPDATA%\TianyuanWorkbench\安装检查结果.txt`
7. 核对检查报告中的“安装模式”和“安装耗时”。如果已有 CLI、Python 和 openpyxl，预期应显示快速安装。
8. 完全退出浏览器后，Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
9. 开启开发者模式，点击“加载已解压的扩展程序”，选择：
   `%LOCALAPPDATA%\TianyuanWorkbench\projects\天源评估系统\extension`
10. 确认扩展名称为“天源浏览器工作台”，扩展 ID 为：
   `lkflndcnklpeaejohaacoaolnmhgigoc`
11. 打开用户已经登录的天源系统底稿页面，打开扩展侧栏。
12. 进入“连接配置”，先点击“启动/检查”。
13. MCP token 必须由用户本人在插件弹窗中输入。不得要求用户在聊天中发送 token，不得读取、复制、记录或回显 token。
14. 点击“授权 CLI”，让用户在浏览器中自行完成账号授权；不得读取或记录密码、验证码、Cookie 或 Authorization。
15. 授权后再次点击“启动/检查”，确认 Helper、MCP、CLI 三项连接状态。
16. 先执行最小测试：
    - 一个公司；
    - 一个科目；
    - 批量保存使用预演模式；
    - 导出使用临时空文件夹；
    - 打印格式使用工作副本和“在源文件夹创建副本”；
    - 批量上传只验证目标对象和文件映射界面，不在正式底稿执行上传或保存；
    - 批量清理附件只验证对象识别、选择和确认页面，不在正式底稿执行清理或保存。
17. 确认十个功能模块均可打开，并确认：
    - “批量清理附件”页面明确说明清空核实程序和资料索引、保留核对情况；
    - “版本更新”页面可以连接 GitHub Releases；
    - “反馈”页面可以保存本机草稿、执行隐私检查和复制反馈；
    - 更新检查不要求或读取 MCP token；
    - 点击下载前会显示目标平台、安装包名称和 SHA-256 信息。
18. 输出最终结果：安装模式、安装耗时、是否复用已有 CLI/Python、三项连接状态、扩展 ID、十个模块是否可打开、GitHub 更新检查结果、最小测试结果、仍需人工确认的问题。

安全边界：

- 不绕过编辑锁；
- 不修改正式底稿做安装测试；
- 不保存 Cookie、Authorization、密码、验证码或 token；MCP token 仅在当前侧边栏会话中使用；
- 不把文件名前端回显误判为保存成功；
- 没有系统回读或输出文件校验，不宣称任务成功。
