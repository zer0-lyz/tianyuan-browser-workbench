# 公司树形选择静态验证

时间：2026-07-22 23:31:23 CST

## 问题现象

用户要求公司选择逻辑与科目一致：

- 去掉“公司范围”下拉。
- 默认勾选当前公司。
- 点击加载后显示公司清单。
- 公司清单显示层级关系。
- 公司显示为 `公司编号 公司名称`。
- 加载后显示“全选 / 全不选 / 确认”。

## 修正内容

- 移除面板中的“公司范围”下拉。
- 刷新页面后，公司清单默认显示当前公司并勾选。
- 公司加载后使用树形渲染，复用科目树折叠交互。
- 公司显示格式改为 `公司编号 公司名称`。
- 支持 MCP 返回的 `path/fullPath/namePath/parentName/parentCompanyName/parentId/parentCompanyId` 等层级字段。
- 加载公司后显示“全选 / 全不选 / 确认”。
- 加载公司后未确认选择时，不允许运行批量保存。
- 批量保存底层 `companyScope` 自动从确认选择推导：
  - 未加载清单：当前公司。
  - 只选当前公司：当前公司。
  - 全部勾选：全部公司。
  - 部分勾选：部分公司。

## 验证结果

- `extension/src/sidepanel/sidepanel.js` 语法检查通过。
- `native-helper/native_host.js` 语法检查通过。
- `native-helper/server.js` 语法检查通过。
- `extension/manifest.json` JSON 解析通过。

## 后续验证

重新加载 Chrome 扩展后：

- 刷新侧栏应默认显示当前公司已勾选。
- 点击“加载清单”后应显示公司编号和公司名称。
- 如 MCP 返回父级/路径字段，应显示折叠层级。
- 点击确认后再运行批量保存。
