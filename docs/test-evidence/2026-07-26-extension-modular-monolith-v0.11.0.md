# `0.11.0` 浏览器扩展模块化验证

日期：2026-07-26

## 实现结果

- 新增五个公共模块基础设施文件。
- 新增九个功能模块清单，模块 ID 和路由均唯一。
- “版本更新”拥有独立脚本、模板、样式、状态和生命周期。
- 旧更新状态会迁移到模块命名空间存储。
- 主侧栏不再包含 `check_github_update` 或更新检查函数。
- 主 HTML 只保留更新模块页面挂载点。
- 更新模块样式已从主 CSS 移除。
- 本机安装器会校验关键模块文件是否存在。
- 当前版本、构建编号或运行指纹变化时，更新模块会丢弃旧缓存并立即重新检查。
