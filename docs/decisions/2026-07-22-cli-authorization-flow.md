# 决策：CLI 授权由面板触发 tycpv login

日期：2026-07-22

## 背景

用户希望 CLI 与 MCP 类似：如果未连接或未授权，可以在插件面板点击配置/授权，弹出授权页面，授权完成后自动进入可用状态。

## 决策

- 面板新增“授权 CLI”按钮。
- 点击后通过 Native Messaging 调用本机 `/usr/local/bin/tycpv login`。
- `tycpv login` 负责打开浏览器登录授权页面。
- 授权完成后，用户点击“启动/检查”刷新 CLI 状态。

## 边界

- 当前 `tycpv` 暂未提供独立登录状态检查命令；面板可稳定检查 CLI 是否安装可用，授权成功后的业务命令可在后续任务中验证。
- 插件不读取或保存 CLI 登录态内容。
- CLI 授权状态由 `tycpv` 自身维护。
