# 天源浏览器工作台 Extension

当前版本包含只读上下文面板和“批量保存底稿”任务模板。

## 加载方式

1. 打开 Chrome 扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`extension/`。
5. 打开 `https://excel.zhrdc.net/ty/*` 的资产基础法底稿页面。
6. 点击扩展图标打开侧边栏，点击“刷新”读取页面上下文。

## 当前读取内容

- 项目 ID、主体 ID、subjectCode。
- 当前 URL 是否为资产基础法底稿页。
- 当前 sheet、活动单元格。
- 是否找到“查证资料索引”表头。
- 目标行对应单元格是否为 `operation-upload-cell`。
- 保存按钮是否可见。
- 页面疑似编辑锁或登录状态文本。

## 批量保存底稿

侧边栏支持第一个任务模板：

- 科目代码：默认当前科目，也可输入多个科目。
- 科目：从页面左侧科目树和当前底稿读取后，在面板里用复选清单选择。
- 公司范围：当前公司、部分公司、全部公司；部分公司可加载公司清单后在面板里多选。
- 执行方式：预演或正式执行。

预演模式只定位页面、按钮和范围，不点击保存。正式执行会点击天源页面的“保存”，必须先勾选确认。

## 门禁

保存动作必须继续保留预演、执行、回读三个阶段，并遵守项目管理规则。插件不保存 Cookie、Authorization、密码、验证码或 token。
